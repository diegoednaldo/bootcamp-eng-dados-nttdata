# Bootcamp NTT DATA - Engenharia de Dados com Python

Este repositório contém as atividades e projetos que desenvolvi durante o **Bootcamp NTT DATA - Engenharia de Dados com Python**. O bootcamp foi uma jornada intensiva que cobriu desde os fundamentos da linguagem Python até técnicas avançadas de engenharia de dados e visualização com Power BI.

## Sobre o Bootcamp

O **Bootcamp NTT DATA - Engenharia de Dados com Python** é um programa de capacitação que visa preparar profissionais para atuar na área de engenharia de dados, utilizando Python e Power BI. O bootcamp aborda desde conceitos básicos até técnicas avançadas, incluindo programação orientada a objetos, manipulação de dados, modelagem de dados, e criação de dashboards interativos.

O bootcamp foi estruturado em módulos, cada um com foco em um conjunto específico de habilidades e ferramentas. Abaixo está um resumo dos módulos e atividades realizadas:
